# Security policy

Pairwise is an early-stage collaboration app. Do not use it for sensitive or regulated information. The self-hosted LiveKit server can access media; app-level end-to-end encryption is not provided.

Please report suspected vulnerabilities privately to the repository maintainers. Do not publish credentials, account backups, session tokens, private deployment logs, or an unpatched exploit in an issue. Include the affected version, impact, and a minimal reproduction. Maintainers can coordinate a fix and disclosure date with the reporter.

Rotate any secret that was accidentally committed, even after deleting it from the current revision. Use GitHub secret scanning and history cleanup as additional response steps.
