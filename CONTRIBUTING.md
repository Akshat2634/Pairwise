# Contributing

Thanks for helping improve Pairwise. Start with a focused issue or pull request and include the macOS version and hardware model for platform-specific bugs. Never include team credentials, account data, session tokens, or unredacted deployment logs.

Before opening a pull request, run the server and macOS test commands in the README. Changes to capture, remote input, permissions, or media transport should explain how they were exercised on physical Macs. Do not claim UI tests prove TCC, sleep/wake, Accessibility, or cross-network TURN behavior.

Keep third-party source and model licenses intact. Add any bundled library, binary, or model to `THIRD_PARTY_NOTICES.md` and preserve its notices in packaged applications. Pairwise does not accept copied code from Hopp or other projects without a compatible license and clear attribution.
